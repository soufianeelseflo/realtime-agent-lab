# Governance

Realtime Agent Lab is maintained in public. Maintainers review issues, pull requests, releases, security reports, benchmark changes, and specification changes.

## Decision process

- Bug fixes and fixtures: one maintainer approval.
- New adapters: one maintainer approval plus tests.
- Metric or specification changes: proposal issue, compatibility notes, tests, and changelog entry.
- Security-sensitive changes: private review through the security reporting process before disclosure.

## Becoming a maintainer

Contributors may be invited after sustained, high-quality participation across code review, issue triage, tests, documentation, or releases.
