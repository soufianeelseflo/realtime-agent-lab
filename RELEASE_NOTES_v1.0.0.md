# Realtime Agent Lab v1.0.0

The first stable release introduces an open, provider-neutral reliability standard for real-time voice and multimodal agents.

Highlights:
- RAL Session Spec 1.0
- deterministic composite scoring
- CLI and GitHub Action
- multilingual public fixtures
- OpenAI Realtime, Gemini Live, Twilio, and generic WebSocket adapters
- secret scanner and redactor
- CI, CodeQL, dependency review, OpenSSF Scorecard, and GitHub Pages
