# Repository Instructions

Realtime Agent Lab is a GPL-3.0-or-later maintained fork of `sohzm/cheating-daddy`.

## Commands

```bash
npm install
npm test
npm run check
npm start
```

## Rules

- Preserve `LICENSE`, `NOTICE`, and upstream attribution.
- Mark substantial modifications in `CHANGELOG.md`.
- Never log API keys, recordings, transcripts, or personal data.
- Validate renderer-to-main IPC inputs.
- Keep heavy audio processing off the UI thread.
- Add tests for new provider, consent, replay, and evaluation behavior.
- Do not add features primarily intended for covert cheating, exams, or non-consensual recording.
- Use four-space indentation, semicolons, and single quotes.
